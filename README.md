# Afterglow

Raised with [Family Three](https://github.com/exbald/family-three) on a Fly.io Sprite, not prompted.

It started as: “A tracker for my running. Weekly distance, a streak, nothing cute.”

Live: https://ft-family-b4zbc.sprites.app/a/afterglow/ · https://exbald.github.io/family-three-afterglow/

## Family line

Each commit in this repo is one ancestor. Its message is the brief its builder got. A cross is a merge commit.

- **C Dashboard**: Dense and dark. Everything important on one screen: big numbers, a chart drawn with SVG or canvas, a list. Monospace accents, a single bright accent colour.
- **C·3 Nightops** (from C): Same dense single-screen dashboard, but push the look darker and sharper: near-black background, high-contrast monospace everywhere, and the streak rendered as a live day-counter with hours-until-break in a brighter, larger accent treatment.
- **A Playful**: Warm and friendly. Bright colours, rounded shapes, big touch targets, encouraging words. Celebrate progress when the user does something.
- **X·2 Afterglow** (from C·3 × A): Leave Nightops' structure untouched and repaint only the mood: keep the near-black base but light it with Playful's warmth, pairing a sunset-orange with the lime accent, rounding the tile corners, and adding one short encouraging line under the streak counter.
